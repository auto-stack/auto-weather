# PLAN-007 i18n（zh/en 全量语言切换）

## 0. 变更摘要

落地中英双语切换，收官 spec 最后一个未立项需求。后端：设置面增 `lang`
（zh/en）；`report/report_at` 增 `lang` 参数、`search` 增 lang（Geo
language 参数化）；所有后端中文字符串（星期/生活指数/AQI 等级/风向/
WMO 中文文案/"现在·今天"标签/mock 兜底默认值）经 `L(zh, en, lang)`
单点收口双语化。前端：约 32 个 `t_*` label 变量 + `ApplyLang` 双块
赋值；视图全部字面量（搜索/按钮/指标/设置/城市名/f-string 前缀）改绑
变量；设置卡加语言 pill。切换语言后刷新一次即全量生效（数据面语言随
报文，界面语言即时）。横竖屏双份视图字面量同改（PLAN-004 同构复制
的双份都要替换）。

## 1. 目标

- **Goal**：设置中心切 中文/English：界面文案、报文文案（星期/指数/
  等级/风向/天气现象）、搜索框与结果、mock 兜底全部跟随。
- **Non-goals**：更多语言（框架按两语实现，扩展为表驱动增量）；
  城市名罗马化转写（内置城 en 用通用英文名片段）；QW 预警文案
  （alert 契约仍为占位）。
- 受影响模块：`src/back/api.at`、`src/front/app.at`、`tests/vm_smoke.py`、
  README、`docs/specs/weather-app.md`。
- 成功标志：AC-01..AC-05 全过。

## 2. 架构方案

后端 `L(zh,en,lang)` helper 全面替换中文字符串返回点；`weekday_calc`
/`weekday_zh`/`weekday8` 增 lang 透传；`cond_zh_for` 逐返回 L 化；
`aqi_level`/`index_*`/`wind_dir_zh` 增 lang 参数；QW 路径 cond en 走
`cond_en_for(category)` 类别表（probe QW `lang` 参数，不支持则表）。
前端 label 变量化（动态 label 绑定先例：h.label/c.name/.s_default_label）；
`ApplyLang` 两个大块（zh/en）赋值全部 t_*；`SetLang` 持久化 + ApplyLang
（数据面语言下次取数生效，T13 流程含刷新步骤）。

## 3. 技术栈

AutoLang .at（model label 绑定 / `#[api]` 参数扩展）、Open-Meteo
language 参数、vm_smoke MCP。

## 5. 详细设计

### 5.1 后端（src/back/api.at）

- `SettingsOut` 增 `lang str`（默认 "zh"；set 校验 zh/en）；
  settings.json 增字段。
- `weather_report(city, ut, uw, lang)` / `weather_report_at(lat, lon, ut,
  uw, lang)` / `weather_search(q, lang)`（geocoding `language=zh|en`）。
- `fn L(zh str, en str, lang str) str`；`fn cond_en_for(cat str) str`
  （7 类英文表）。
- 双语化点：`weekday_calc(y,m,d,lang)`/`weekday_zh(ds,lang)`/
  `weekday8(iso,lang)`；`cond_zh_for(code,lang)`（全部返回点 L 化）；
  `aqi_level(a,lang)`；`index_dressing/carwash/sport/cold(feels…,lang)`
  及指数 note 组装；`wind_dir_name(deg,lang)`（原 wind_dir_zh 更名）；
  hourly/daily 首标签 `L("现在","Now",lang)`/`L("今天","Today",lang)`；
  impl_report_ll 开头按 lang 覆盖 mock 默认文案（en 默认集）；
  QW current：lang=en 时 `cond_zh = cond_en_for(qw_condition(code))`
  （QW API text 恒中文——probe `?lang=` 若支持则直接用）。
- OM indices 名（穿衣/洗车/…）与 note 在装配处 L 化。

### 5.2 前端（src/front/app.at）

- model 增 `lang str = "zh"` + t_* 约 32 个（搜索/搜索占位/横屏/竖屏/
  刷新/刷新中/更新于/体感/湿度/风/24小时/5日/当前详情/紫外线/能见度/
  气压/更新/数据/生活指数/24小时降水/演示注记/设置/温度单位/风速单位/
  默认城市/语言按钮 2 + t_city_beijing..sanya ×10）。
- `ApplyLang`：lang 两分支大块赋值；`Init` 消费 settings.lang 后调用；
  `SetLang(l)`：写 model + ApplyLang + settings_set（四参整对象）。
- 设置卡加 `中文 / English` pill 行；视图字面量全量改绑 `text .t_*` /
  `button .t_*`（含 portrait 双份）；f-string 四站点改 lang-if 双行
  （zh f-string / en f-string）；城市 pill label 绑 t_city_*（id 判断不变）。
- 六个取数调用点传 `.lang`；`.data_note` 演示分支文案入 t_* 变量。

### 5.3 测试（tests/vm_smoke.py）

  还原 zh（跨运行卫生双保险）。既有 T1–T12 全回归（zh 默认）。
